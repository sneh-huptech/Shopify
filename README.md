
# Shopify Theme Development

A local Shopify theme development project.

## Project Goals

- Learn Shopify theme architecture and Liquid.
- Build and customize Shopify themes locally.
- Use Git and GitHub for version control and backup.
- Follow a structured development workflow.

## Git Branches

- `main` — stable project version.
- `develop` — integration and testing.
- `feature/*` — individual features and changes.

## Technology Stack

- Shopify Liquid
- HTML
- CSS
- JavaScript
- Shopify CLI
